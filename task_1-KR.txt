Сигнатура: range(stop), range(start, stop), range(start, stop, step).
start по умолчанию 0, step по умолчанию 1. Значение stop не включается.
range возвращает объект range, а не список. Он ленивый: числа вычисляются по мере необходимости, поэтому занимает мало памяти.
Примеры: list(range(5)) даёт [0, 1, 2, 3, 4], list(range(2, 10, 3)) даёт [2, 5, 8], list(range(5, 0, -1)) даёт [5, 4, 3, 2, 1].
